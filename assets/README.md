# Recursos visuais

[Página inicial](../README.md) · [Índice do livro](../book/README.md)

Área para diagramas, figuras, capturas e seus arquivos-fonte. A presença deste diretório não significa que todos os capítulos tenham ilustrações prontas.

Cada recurso deve identificar o capítulo que o utiliza, seu contexto e sua autoria. Capturas ilustrativas não devem ser apresentadas como evidências de execuções que não ocorreram. Não incluir credenciais, tokens ou dados pessoais reais.

Materiais de terceiros exigem licença ou permissão adequada e atribuição. Consulte o [mapa de licenciamento](../LICENSE.md). Fontes tipográficas e recursos proprietários não devem ser copiados apenas para facilitar uma geração de PDF.
