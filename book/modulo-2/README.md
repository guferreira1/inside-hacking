# Módulo II — Computadores por dentro

[← Módulo I](../modulo-1/README.md) · [Índice do livro](../README.md) · [Página inicial](../../README.md)

No primeiro módulo, construímos perguntas para investigar sistemas. Agora começamos a abrir esses sistemas: como representam informação, onde a guardam e o que significa executar um programa.

Antes de analisar uma falha de memória ou uma mensagem de rede, precisamos reconhecer o material de que elas são feitas. Um número mostrado na tela, os bytes de um arquivo e as instruções de um programa não são a mesma coisa, embora se apoiem em representações binárias.

## Como ler

O capítulo 6 desenvolve representações e contas passo a passo. O capítulo 7 acompanha o caminho de uma alteração de texto para explicar as funções do hardware. Nenhum dos dois exige programação, montagem de circuitos ou instalação de ferramentas. As perguntas de revisão são opcionais. Use o [glossário](../glossario.md) para consulta e as referências de cada capítulo para verificar suas bases.

Este módulo está em produção. O [controle editorial](../../editorial/publication-status.md) distingue leitura aprovada, revisão interna e edição publicada.
