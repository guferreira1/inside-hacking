# Pesquisa

[Página inicial](../README.md) · [Editorial](../editorial/README.md) · [Bibliografia](../book/bibliografia.md)

Notas e experimentos que sustentam a obra. Seu conteúdo não integra automaticamente o manuscrito. Registre o que foi consultado, qual afirmação a fonte sustenta e o que permanece incerto.

As explicações do livro devem ser autorais; não copie documentos inteiros como substituto de pesquisa. Preserve origem, licença e contexto de materiais de terceiros. Dados sensíveis, credenciais e vulnerabilidades privadas não pertencem a esta área pública.

Fatos documentados, hipóteses, exemplos fictícios e resultados efetivamente observados devem permanecer distinguíveis. A [política de glossário](../editorial/glossary-policy.md) também se aplica quando uma pesquisa introduzir terminologia no manuscrito.
